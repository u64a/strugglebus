# setup/debloat.txt: what setup/10-debloat.ps1 removes and sets on a DEDICATED host (agent-host-build.md section 6).
# Reviewed by the owner. One entry per line; `#` starts a comment. Names are exact (no wildcards).
#
#   app     <package name>                     removed for all users AND as a provisioned package (new profiles)
#   keep    <package name>                     never removed; an `app` line naming it is an error
#   feature <optional feature name>            disabled (Disable-WindowsOptionalFeature, no restart)
#   policy  <HKLM\path> <value name> <dword>   machine policy, so Windows does not put things back
#   user    <path> <value name> <dword>        per-user setting, written to the user running the script AND to
#                                              the Default profile (so every new profile starts with it)
#   onedrive                                   OneDrive uninstalled for this user; new profiles never install it
#
# Checked against a fresh Windows 11 Enterprise 26H2 image (en-us_windows_11_business_editions_version_26h2,
# the Surface Laptop 4 test host, 4 Nov 2026). Lines marked (not on 26H2) cover older or other images; a line for
# something that is not there does nothing.
#
# Undo, line by line:
#   app      winget install --id <Store id> -s msstore, or the Microsoft Store page; nothing else depends on these
#   feature  Enable-WindowsOptionalFeature -Online -FeatureName <name>
#   policy / user   delete the value (regedit, or Remove-ItemProperty), then sign out and in
#   onedrive winget install Microsoft.OneDrive, and delete the DisableFileSyncNGSC policy value
#
# Deliberately NOT here (section 6): disabling services wholesale, hosts-file telemetry blocks, removing Store,
# Edge or Defender, and anything from third-party debloat scripts.
